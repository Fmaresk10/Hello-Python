# CAFASSO · Visual loops piloto

Esta carpeta contiene las capas de video ambientales que se superponen a la escena base.

## Pilotos esperados

- `house-sunset.mp4` — Casa · atardecer
- `patio-sunset.mp4` — Patio · atardecer
- `school-night.mp4` — Escuela · noche
- `parish-night.mp4` — Parroquia · noche

## Exportación recomendada

- MP4 / H.264
- Sin audio
- 1280×720 como referencia
- 10–20 s
- Loop visual sin corte perceptible
- Movimiento lento y sutil
- Peso objetivo: lo más bajo posible sin degradación visible

CAFASSO mantiene la imagen base como escenario. El video funciona solo como capa atmosférica.
Si un archivo no existe o no puede reproducirse, el motor conserva la ambientación actual sin romper la escena.
