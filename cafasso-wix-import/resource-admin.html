Administración CAFASSO

Cargar recurso

Registrá el material una sola vez. Después CAFASSO podrá mostrarlo en la Biblioteca y reutilizarlo en los cursos.

Volver a Recursos
Para archivos propios, guardalos primero en Wix Media Manager, dentro de la carpeta CAFASSO Recursos, y pegá aquí la URL del archivo. Al continuar se abrirá GitHub para confirmar el alta; después la automatización actualizará el catálogo y el libro aparecerá solo.
